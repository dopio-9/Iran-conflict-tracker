# TRACE — Food / Metabolic Tracker (separate project)

**This is NOT part of the Iran Conflict Tracker.** TRACE is a separate app — a
metabolic/food tracker built as a Claude artifact — parked in this repo purely
as reference material until it gets a home of its own. Nothing here is wired
into the live tracker build, and nothing from `design-lab/` applies to it.

## design-ideas/ — concept archive

Standalone concept boards, not production code. None of it is meant to be
imported into the TRACE React component as-is. Each file renders standalone in
a browser (only external call: Google Fonts).

| File | Concept |
|---|---|
| `design-ideas/seismograph-v2-concept.html` | **Seismograph v2** — recommitting the metabolic trace to its instrument metaphor. Annotated phone mockup (SVG) + numbered legend mapping each proposed change to the weakness it fixes: phosphor bloom, live pen-head at NOW, restored event spikes, balance-tinted glow, leader lines, integrated balance gauge. |

## To resume
Open any `.html` directly in a browser. When picking the redesign back up,
read the legend in the concept file first — it records *why* each change was
made, not just what changed.
